# NASSR HUB | نصر هَب

تطبيق جماهيري عربي لنادي النصر، مصمم للجوال ويعمل كتطبيق ويب قابل للتثبيت (PWA).

## الموجود حاليًا
- بحث داخل اللاعبين والبطولات والتاريخ
- قاعدة أولية للاعبين والأساطير
- خزانة بطولات قابلة للتوثيق والتوسعة
- خط زمني لتاريخ النادي
- مركز إحصائيات مهيأ لإضافة بيانات الموسم
- تصميم أصفر/أزرق مناسب للنصر
- PWA + وضع Offline أساسي

## تشغيل GitHub Pages
من Settings > Pages اختر **Deploy from a branch** ثم `main` و`/(root)`.

بعد النشر يصبح الرابط:
https://drburghash-sys.github.io/alnaser/


## بنية البيانات
أصبحت المعلومات مفصولة عن الواجهة داخل مجلد `data/`:
- `current-players.json` — لاعبو الفريق الحالي
- `legends.json` — الأساطير والرموز والنجوم التاريخيون
- `seasons.json` — أرشيف المواسم وربط كل موسم بنجومه
- `trophies.json` — البطولات مع فصل الدوري التصنيفي عن الدوري الممتاز/المحترفين
- `fixtures.json` — المباريات
- `history.json` — الخط الزمني

### سياسة المصادر
**المصدر الأول للألقاب والأرقام التاريخية هو موقع نادي النصر الرسمي `alnassr.sa`.**
إذا تعارض رقم يعلنه النادي مع مرجع ثانوي، يعرض التطبيق رقم النادي كرقم أساسي، ويحتفظ بالمصدر الآخر كتفصيل توثيقي فقط.
الترتيب بعد موقع النادي: الاتحاد السعودي → رابطة الدوري → AFC → المصادر الأرشيفية.


## أرشيف المواسم
أصبح الأرشيف يحتوي على **53 سجلًا** من موسم 1974/75 حتى 2026/27.
- المواسم الحديثة التي راجعنا ترتيبها ونقاطها موسومة بأنها موثقة إحصائيًا.
- المواسم الأقدم غير المفحوصة مصدرًا بمصدر موسومة «أرشيف أولي».
- اللاعب مرتبط بالمواسم التي يظهر فيها كأحد نجوم الحقبة، والموسم مرتبط بملفات لاعبيه.


## اعتماد سجل الدوري الرسمي
يعتمد التطبيق الرقم الرسمي الذي يعرضه نادي النصر: **20 لقب دوري** في جميع مسميات البطولة.
السنوات المحفوظة كما تظهر في سجل النادي:
1961، 1963، 1966، 1968، 1969، 1970، 1971، 1972، 1974، 1974، 1975، 1980، 1981، 1989، 1994، 1995، 2014، 2015، 2019، 2026.
ويُحفظ تكرار 1974 كما هو في السجل الرسمي، دون دمجه أو إعادة تصنيفه.
